# Implementation interfaces

All paths are pathlib.Path. Public artifact JSON has `version: 1`; unknown or duplicate keys in strict input envelopes are rejected. Python dictionaries represent JSON records; byte SHA256 is lowercase hex.

- `corpus.load(root: Path) -> dict`: validated tasks, schemas, worlds and later gold/control assets. `corpus.materialize(schema: dict, world: dict, destination: Path) -> None`: new constraint-checked SQLite database. `corpus.build_worlds() -> dict`: deterministic small row fixtures. World record: `{id, schema, seed, role, tables: {table: [row-object]}}`.
- `execution.execute(db: Path, sql: str, tables: list[str], timeout: float = 2.0) -> dict`: `{status, columns, rows, error, elapsed_seconds}`, status `ok|policy|limit|timeout|error|worker_crash`. Time is local execution wall time, not model latency. `execution.compare_result(task: dict, expected: list[list], actual: dict) -> dict`: `{pass, reason}`, with typed bag/order semantics.
- `freeze.create(root: Path, destination: Path, oracle_review: Path) -> dict`: versioned immutable file-hash manifest, planned task response slots, grading limits and oracle agreement binding. `freeze.verify(root: Path, frozen: Path) -> dict`: reject any changed input/source. `freeze.public_prompt(root: Path) -> str`: only schemas/task contract/answer instructions, no worlds/gold.
- `imports.import_candidates(root: Path, frozen: Path, raw: Path, destination: Path, kind: str, cohort: str) -> dict`: validate/copy immutable raw+canonical input and hashes. Canonical candidate: `{id, task_id, sql, label?, label_kind?, rationale?}`; agent captures can omit task entries and the run still retains every planned response slot. Input JSON envelope: `{version:1, candidates:[...]}`. Control labels only `positive|negative|sanity`; no model labels.
- `runs.evaluate(root: Path, frozen: Path, imported: Path, destination: Path) -> dict`: create or verify immutable manifest, lock run, append unique per-slot/world outcomes and resume. `runs.read(root: Path, destination: Path) -> dict`: validate current integrity, return outcomes including missing slots/worlds.
- `report.summarize(root: Path, run: Path) -> dict`: exact/single/multi summaries by task/split/category plus explicit denominator classes. `report.inspect(root: Path, run: Path, candidate_id: str) -> dict`: candidate plus first failure's complete small-world rows/results. `report.html(summary: dict, diagnostics: list[dict]) -> str`: escaped standalone document. CLI exposes these in `python3 -m queryproof` with explicit paths and structured JSON errors.

CLI public run interface and artifact shapes may receive bounded refinements during implementation; any semantic/limit change is versioned and invalidates an earlier freeze. Root capture only begins after final public task/prompt freeze.
